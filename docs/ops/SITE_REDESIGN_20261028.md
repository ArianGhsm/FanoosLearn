# Website redesign — 2026-10-28

Scope: website presentation, based on origin/main 7c58cd8. Shared page surfaces, controls and footer, the public landing page, sign-in/registration, signed-in home, and shared bank, exam, practice, progress and account surfaces were restyled. Application logic, question data, bots and API contracts were not changed. Existing brand and semantic answer colours remain.

Validation: `node --test tests/web/*.mjs` passed 156 tests; `php scripts/ci/check-text.php` passed. `FANOOS_TEST_MODE=all FANOOS_ALLOW_TEST_DB=1 php tests/run.php` passed 2,508 assertions against a newly created disposable `fanoos_redesign_20261028_test` database, which was removed with its dedicated test user afterwards. Chrome was used to inspect the landing page at desktop and mobile sizes and the home page at desktop size. A local server-rendered fixture checked for horizontal page overflow in 27 page templates at 390px and 1440px, in light and dark themes (108 combinations); these fixtures do not exercise live data or every interactive state. On the landing page, keyboard Tab reached the visible skip link and reduced motion shortened its entrance animation. Playwright installation failed because the package proxy timed out.

Additional validation: the QA account was used against the live server with the candidate CSS injected in its browser only. Sixteen signed-in routes were checked at 390, 1000, 1200 and 1440 pixels in both themes. A long account name exposed header overflow; the shared header was corrected and checked again at 390, 720, 721, 1280, 1281, 1440 and 1441 pixels. Navigation labels and the bank view tab were checked at four widths. The test did not submit answers or change student data.

Release scope: this is a shared visual refresh, not an individual redesign of every interactive state. Exam-runner answer submission and other mutating workflows were not exercised in the live QA session. Playwright remains unavailable because the package proxy timed out; Chrome DevTools was used for browser checks. Follow `docs/WORKFLOW.md` for green CI, updater deployment and live readback. Reverting the CSS commits restores the previous appearance; there is no data migration.
