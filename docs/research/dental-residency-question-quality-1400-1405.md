# Dental residency question corpus: verification status

The local workbook at `.local/exam-questions/dental-residency/question-corpus-1400-1405.xlsx` contains 2,000 form rows, covering 1400–1405. Forms B in 1402 and 1404 are alternate orderings, not additional exam years. The workbook and raw PDFs are local data and are not Git release artifacts.

The current workbook is **not a verified question bank**. Its prior output audit established that spreadsheet rows matched the generated JSON, not that the words, choices, official answers, editions, or chapters matched their primary sources. In particular, the 1,296 chapter assignments are candidates rather than confirmed book chapters. The current catalog has no chapter nodes.

The per-row audit is generated locally with `python scripts/import/corpus_to_bank.py audit --workbook=<xlsx> --out=<json>`. Its current result is `.local/exam-questions/dental-residency/question-quality-audit.json`. Across all form rows it flags 525 absent question texts, 33 additional stems or option sets requiring review, one unreadable official final key, 685 absent question-level references, 56 selected editions absent from the catalog, and 48 publication-year conflicts with catalog editions. It also flags 63 chapter assignments outside the official scope, 12 multi-chapter candidates, nine section-only candidates without a verified parent chapter, 36 instances of page headers in question text, and five course disagreements between a correction notice and the question PDF. Every 1405 row is flagged for page review because its PDF text layer is unreliable. These issue counts overlap; they must not be added as a count of distinct bad questions.

The 1401 page review found that questions 245 and 249 were present in the PDF text layer but swallowed by adjacent questions. All ten reading questions 241–250 were resegmented from selectable text, checked against the printed pages, and given their shared passages so each question has its context. The workbook, JSON and subject text export now agree. The 25 unavailable 1403 rows occur on six pages with almost no selectable text; its alternate PDF has the same gaps.

On printed page 13 of the 1405 booklet, Q81 had been merged into Q80 in the extracted text. Old rows 81–109 therefore represented printed questions 82–110, while row 110 was an empty placeholder. Q80 and Q81 were separated using selectable text, rows 82–110 realigned, and the placeholder removed. The Q81 tooth diagram and corrupted words are still unresolved; the nonempty text field is not evidence of a valid transcription. Official keys remain attached by printed question number. No OCR was used.

Publisher tables of contents for 13 exact editions were compared with chapter number and title. Thirty-eight row titles were corrected to the publisher's wording; the local correction ledger retains the old/new titles and publisher URL. This verifies chapter **identity**, not that a particular question is answered in that chapter. No question-to-chapter content match has been certified by this pass. The 1404 reviewed file has 250 stems and four choices per question, but no checked image assets or checked source/chapter fields; it is still blocked from import.

The 1405 PDFs already available locally, including the 1.9 MB DentalMindset copy, share the same faulty text layer. A separate 1.3 MB copy from Telegram channel `medicaluniversity`, post 23718, has the same extraction defect. It is saved only as source evidence under `.local/exam-questions/dental-residency/alternate-sources/`. No OCR was used.

`scripts/import/corpus_to_bank.py` now requires all 250 canonical-form questions to have four reviewed choices, a reviewed reference or explicit inapplicability, a reviewed chapter or explicit inapplicability, and a checked figure status with an asset when needed before it writes an import file. It rejects an edition/year mismatch and multi-chapter strings that would otherwise be silently truncated. It accepts reviewed corrections to the reference and chapter. Alternate form B is blocked from a second import under the same exam sitting. Multiple accepted official answers retain the accepted option list in their provenance text and are marked `disputed`, which the publisher excludes from scored exams. A structured accepted-options field is a separate bank contract change; it has not been invented inside an existing single-choice field.

To complete this corpus without OCR, obtain genuinely selectable or independently transcribed question text for the missing 1402 and 1403 rows, verify each question against the printed booklet, verify every official key against its final notice, and verify each cited chapter against the exact reference edition. Do not publish a sitting until these checks are complete.
