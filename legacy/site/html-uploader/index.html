Upload

آپلود فایل HTML و ساخت لینک موقت

فقط یک فایل HTML تک‌فایلی آپلود می‌شود. اگر فایل شما asset جداگانه دارد، باید آدرس‌هایش داخل خود HTML قابل‌دسترسی باشند.

صفحه‌ی خروجی روی مسیر موقت جداگانه باز می‌شود و با sandbox/CSP ایزوله سرو می‌شود؛ بنابراین به session اصلی سایت دسترسی ندارد.

برای جلوگیری از abuse، سقف روزانه و سقف حجم روی این uploader فعال است.
